## 二、功能清单(按 5 个代码工程)

### 1. Core:NetDisk.ClientCore(平台无关核心,零 WPF / 零 WinAPI)
| 文件 | 功能 |
|---|---|
| `LoopbackLogin.cs` | 系统浏览器 + loopback + PKCE S256 登录(DE-D-03) |
| `NameRules.cs` | 名字规则/兜底(DE-D-02) |
| `PathBudget.cs` | 路径预算预检(≤240B) |
| `ConflictNaming.cs` | 冲突命名确定性算法(`_conflict_`) |
| `SpaceCursor.cs` | 空间游标 |
| `Generated/Models.g.cs` | 契约生成的 C# 模型(禁手改) |

### 2. Transport:NetDisk.Transport(REST / TUS / WebDAV 传输层)
- `ApiClient.cs`(REST/WebDAV 封装,base_version 注入、409 reason 解析、429/5xx 退避尊重 Retry-After、POST 不自动重试)
- `AuthApi.cs` / `TokenSession.cs`(令牌);`TusUploader.cs`(**TUS** 分片 + ticket + 断点续传)
- `SpaceCollabClient.cs`(协作/分享接口);`SseParser.cs`(SSE 解析)
- `ClientOptions.cs` / `ITokenStore.cs`

### 3. SyncEngine:NetDisk.SyncEngine(同步引擎,与 UI 正交)
| 子域 | 文件 | 功能 |
|---|---|---|
| 状态机 | `Sync/SyncStateMachine.cs`、`SyncState.cs` | 同步状态机,含 PendingRemoteGone/权限受限(DE-D-09) |
| 变更感知 | `Watch/FileWatcher.cs`、`Watch/DirectoryScanner.cs` | FileSystemWatcher + 定向重扫 + 自适应卫生扫(DE-D-08) |
| 游标双态 | `Sync/ChangeFeedSync.cs`、`Host/SseChangeStream.cs` | SSE 消费 + `/changes` 双态,重连先逐空间补拉(DE-D-13) |
| 冲突解决 | `Sync/ConflictResolver.cs`、`Host/ConflictResolution.cs` | version 裁决 + 确定性冲突副本(DE-D-12) |
| 记账 | `SqliteExpectedChangeSink.cs`、`Sync/ExpectedChangeLedger.cs` | 自触发销账(期望变更表,DE-D-10) |
| 身份 | `Sync/FileIdentity.cs` | rename 识别(FileId 不重传)+ 失效降级为哈希(DE-D-11) |
| 传输队列 | `Transfer/TransferQueue.cs`、`Transfer/RateLimiter.cs` | 并发 ≤3 + 上下行限速 + 最小化后继续传(DE-D-14) |
| 状态库 | `StateStore.cs` | 本地 SQLite,表结构 schema 版本化、迁移不回退(DE-D-07) |
| 令牌 | `DpapiTokenStore.cs`、`TokenSession.cs` | DPAPI 加密落盘 + 静默刷新 + 被吊销退出(DE-D-04) |
| 首次引导 | `Onboarding/OnboardingPlan.cs` | 三选(仅结构/限定子树/节流)、容量预估、只读浏览模式(DE-D-15) |
| 路径 | `Paths/LongPath.cs`、`Paths/LocalNameGuard.cs` | 长路径(\\?\ 前缀)+ 本地名兜底(DE-D-16) |
| 更新 | `Update/UpdateOrchestrator.cs`、`Update/ProcessRunner.cs`、`Update/UpdaterRunner.cs`、`Update/UpdaterLauncher.cs` | 升级四步(暂停→排空→迁移→重启)+ 失败回滚 + 恢复同步(DE-D-19) |
| 通知 | `Notify/NotificationCenter.cs`、`Notify/StartupRegistration.cs` | 托盘/Toast/开机自启/合并窗口(DE-D-18) |
| 主机 | `Host/SyncHost.cs`、`Host/SyncRuntime.cs`、`Host/ClientConfig.cs`、`Host/ClientPaths.cs`、`Host/SpaceBinding.cs`、`Host/SyncHostUpdateHost.cs` | 同步宿主、多空间、配置/路径聚合 |
| 远程浏览 | `Files/RemoteBrowser.cs`、`Files/FileApi.cs` | 远端文件浏览器(只读浏览整个空间) |
| 诊断 | `Diag/ThreadDiscipline.cs`、`Diag/SoakProbe.cs` | 线程纪律记账 + soak 采样(DE-D-21) |

### 4. App:NetDisk.App(WPF 主程序,UI 壳)
- `App.xaml.cs`(线程纪律入口)、`MainWindow.xaml.cs`、`AppLog.cs`、`Notify/TrayNotifier.cs`(托盘 marshal)
- `Views/`:LoginView / SyncView(每文件进度,按字节)/ SpacesView / RemoteView / SettingsView(改配置必重启;退出登录必吊销服务端令牌)/ SpacePickWindow

### 5. 分发:单文件 exe(取代原 WiX MSI)
- 发布即 `dotnet publish` 产出**恰好一个** `NetDisk.App.exe`(自包含,无需目标机装 .NET);
- 免安装、可携带:拷贝到任意 Windows x64 即运行;程序目录不可写时回退 `%APPDATA%\NetDisk`;
- 首次运行释放 `client.json`(同目录,带中文 `_说明`),之后每次启动读取;删 exe 即卸载、无注册表残留;
- 自动更新为 **exe 换装模型**:`--apply-update --new-exe <新exe> --client <安装目录exe>`,由客户端临时副本负责备份/换装/`--self-check` 验活/失败回滚(见 `Update/UpdaterRunner.cs`);
- 代码签名目标从 MSI 改为 exe(`signtool` 均可签);本地验收见 `scripts/verify-publish.ps1`。

## 五、产品边界(客户端明确不做/注意)

- **不支持在线预览**(无内置查看器);**不支持"按需下载/占位文件"**(二期范围外)。
- 删除策略:一致优先、两端不弹确认;同步根身份硬保护;403/401 永不删本地(R-19)。
- macOS 无原生客户端(H5/分享落地页覆盖轻访问)。
